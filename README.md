## Ⅰ. 为什么要做这个产品

<aside>
😀

**电商广告创意的核心矛盾**：素材消耗快、迭代频率高，但每次跑完 A/B Test 后，"什么创意策略赢了、为什么赢"的知识几乎不会被系统性沉淀——它们要么停留在投手脑子里，要么散落在平台后台报告里无人整理。

**结果是**：每次大促、每换一个新客户，创意团队都在从零开始试，经验无法复用，爆款素材背后的方法论无法传承。

</aside>

**需要创建一个专门平台做创意结构化沉淀**

- **各广告平台的原生 AB 实验工具**（如巨量千川的创意测试）各自为政，数据孤岛，没有跨平台汇总；
- **Excel/飞书文档**可以手动整理，但打标标准不统一、效率极低；
- **没有一款工具**专门解决"胜出素材 → 创意变量解构 → 可复用方法论"这条链路。

## Ⅱ. 产品定位

一款面向**广告代理商创意策略团队**的轻量级 SaaS 工具，用三步解决"创意知识无法沉淀"的核心痛点：

1. **Step 1（引流钩子）**：用高频的 A/B Test 实验设计计算器建立信任、吸引注册
2. **Step 2（核心功能）**：通过跨平台 API 对接，把散落在各投放平台的胜出素材统一聚合管理
3. **Step 3（核心价值）**：对胜出素材做 AI 自动创意打标，输出可复用的创意策略洞察报告

### MVP边界

**只做**

- 设计规范实验：假设、指标、变量
- 计算样本量、实验周期
- 标准化的复盘结果：统计结果判定、结论生成、报告导出
- 轻量化的创意洞察：基于胜出素材的打标结果，进行定性的洞察建议

**不做**

- ❌ 实验进行中的实时监测与结论建议
- ❌ AI 辅助脚本/分镜内容生成
- ❌ 行业大盘对标（Benchmarking）
- ❌ 仅聚焦视频前3秒 Hook 的专项工具
- ❌ 企业级数据安全/私有化部署方案
